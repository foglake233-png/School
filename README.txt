学校宣传官网（HTML + CSS + JavaScript）

使用方法：
1. 解压后直接双击 index.html 即可查看。
2. 当前图片使用 Unsplash 网络图片，打开网页需要联网。
3. 网站中的学校名称、电话、地址、招生数据均为演示内容，请上线前替换。
4. 后续可将 image/ 中的真实校园图片替换进来，再修改 HTML 中图片地址。
5. 后续可以继续增加后台、新闻管理、在线报名、MySQL 等功能。

主要文件：
index.html 首页
about.html 学校概况
majors.html 专业介绍
enrollment.html 招生信息
news.html 新闻动态
campus.html 校园风采
contact.html 联系我们
css/style.css 样式
js/main.js 轮播、菜单、返回顶部、数字动画
